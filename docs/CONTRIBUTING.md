# Contributing

GoreeCloud Database is currently an early development preview.

1. Create a focused branch and use a pull request; do not push directly to protected `main`.
2. Include tests and update the README and license notices for changed behavior or dependencies.
3. Do not commit tokens, certificates, database dumps, host infrastructure details or secrets.
4. Prefer narrow, reviewable changes; reproduce issues against a disposable local environment.
5. Keep upstream attribution, security and privacy review evidence with any vendored source.
6. Do not label an Android debug build, preview API or synthetic test as production ready.

For security-sensitive disclosures, see [SECURITY.md](../SECURITY.md).
